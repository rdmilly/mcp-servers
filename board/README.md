# board

FastMCP wrapper for Cortex Board API (`cortex-board:9060`). Kanban + architecture board for all projects.

## Tools (15)
list_projects, create_project, delete_project, get_context, get_all_context, get_architecture, get_state, get_canvas, add_card, update_card, delete_card, add_connection, delete_connection, update_position, auto_layout

All tool names prefixed `board__`.
